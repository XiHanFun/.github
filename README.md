# XiHanFun .github

This repository holds the organization profile and the default community files for the [XiHanFun open source organization](https://github.com/XiHanFun). A repository that ships its own copy of any of these files overrides the default here.

| Path                                       | Purpose                              |
| ------------------------------------------ | ------------------------------------ |
| [`profile/README.md`](profile/README.md)   | Content rendered on the organization homepage |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Default code of conduct              |
| [`CONTRIBUTING.md`](CONTRIBUTING.md)       | Default contributing guide           |
| [`LICENSE`](LICENSE)                       | License of this repository           |
| `assets/`                                  | Shared logo and favicon              |

> Only `profile/README.md` is rendered on the organization homepage, so its cross-file links use absolute URLs.

Documents are maintained in pairs; a file name ending with `_cn` is the Chinese version.
